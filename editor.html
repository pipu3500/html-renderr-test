Kindle-Dashboard

Entwurf

Fenster

    Die Layout-Fläche entspricht der Auflösung des Geräts geteilt durch den Zoom. Das Drehen ins Hochformat übernimmt GitHub beim Erzeugen des PNG.

    KINDLE-UNTERKANTE

    Fenster ziehen zum Verschieben, Griffe an Rand und Ecken zum Vergrößern. Mit den Pfeiltasten geht es pixelgenau, mit Umschalt in 10er-Schritten. Der breite Rand zeigt die Unterkante des Kindle.

    GitHub-Zugang

    Lege unter GitHub → Fine-grained tokens ein Token nur für dieses Repository an: Contents: Read and write, optional Actions: Read-only, damit du siehst, wann die PNGs fertig sind. Das Token bleibt in diesem Browser gespeichert und wird nur an api.github.com gesendet.

    Gerät

    Auflösung des Displays im Hochformat, wie das Kindle sie meldet (Breite kleiner als Höhe).
