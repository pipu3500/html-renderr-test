Entwurf

Fenster

    Die Größe des simulierten Displays entspricht dem Querformat 1024 × 758 px. Das Drehen ins Hochformat übernimmt GitHub beim Erzeugen des PNG.

    Fenster ziehen zum Verschieben, Griffe an Rand und Ecken zum Vergrößern. Mit den Pfeiltasten geht es pixelgenau, mit Umschalt in 10er-Schritten.

    GitHub-Zugang

    Lege unter GitHub → Fine-grained tokens ein Token nur für dieses Repository an: Contents: Read and write, optional Actions: Read-only, damit du siehst, wann das PNG fertig ist. Das Token bleibt in diesem Browser gespeichert und wird nur an api.github.com gesendet.
